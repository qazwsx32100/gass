🚀 如何串接至您的 AI 寫程式工具？

本服務在本地端提供標準的 OpenAI 相容協定端點。您在 IDE 中的擴充插件（例如 Cline, Roo Code, Continue, Cursor, Aider 等），只要將 API Base URL 指向本機端點，所有的請求就會自動享受 3 個帳號的負載均衡與 429 自動故障轉移！

1. 通用配置參數 (Universal OpenAI Settings)

Base URL: http://localhost:3333/v1 API Key: any (可填寫任意字串，因為金鑰由本輪調中心代管) Model ID: gemini-2.5-pro 或 gemini-2.5-flash 或 gemini-2.0-flash

2. VS Code / Cline / Roo Code 設定方式

在擴充功能設定中選擇「OpenAI Compatible」：

• API Provider: OpenAI Compatible • Base URL: http://localhost:3333/v1 • API Key: any • Model ID: gemini-2.5-pro

3. Continue.dev (config.json) 設定範例

{ "models": [ { "title": "Gemini 2.5 Pro (3帳號輪調)", "provider": "openai", "model": "gemini-2.5-pro", "apiKey": "dummy", "apiBase": "http://localhost:3333/v1" } ] }

4. 終端機 Aider 寫程式工具指令

aider --openai-api-base http://localhost:3333/v1 --openai-api-key dummy --model openai/gemini-2.5-pro
