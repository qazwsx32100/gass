## 🏠 三、 住家客戶真實數據平均值 (234,769 筆訂單穿透)

1. **加權配瓶數**：**1.34 支 / 戶**（客端壓 1.26 支 + 店端後勤流通備瓶 0.08 支）。
   - 72.4% 單桶戶（壓 1 支）+ 19.4% 雙桶戶（壓 2 支）+ 8.2% 其他戶。
2. **年叫貨頻率與用量**：
   - 平均年叫貨 **5.0 次 / 年**，年叫總量 **6.0 桶 / 年**。
   - 平均用氣週期：**52 天 / 桶**（冬季 23~38 天，夏季 52~73 天）。
3. **鋼瓶年均分攤**：
   $$\text{每桶鋼瓶分攤} = \frac{1.34\text{ 支} \times \$147.67}{6\text{ 桶}} = \mathbf{\$32.98} \approx \mathbf{\$33}\text{ 元 / 桶}$$
4. **住家實質保本底線**：
   $$\$453\text{ (進氣)} + \$70\text{ (運費)} + \$33\text{ (鋼瓶)} = \mathbf{\$556}\text{ 元 / 桶}$$
5. **毛利與貢獻**：
   - 每桶實質淨毛利（以售價 $720~$750 計）：**$164 ~ $194 元 / 桶**。
   - 每戶每年毛利貢獻：**約 $984 ~ $1,164 元 / 戶 / 年**。
