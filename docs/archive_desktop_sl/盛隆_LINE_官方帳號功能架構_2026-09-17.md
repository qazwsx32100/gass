# 盛隆 LINE 官方帳號功能架構（2026-09-17）

## 使用者入口
LINE 官方帳號對話／圖文選單 → LIFF 會員網站 → Vercel API → Supabase 正式資料庫。

## 客戶端功能
- LINE 身分驗證；首次使用送出會員綁定申請，管理者核准後才能取得舊客戶資料。
- 查看本人商品售價、配送地址與訂單。
- 叫瓦斯、再次下單、查看五階段配送進度。
- 申請新增地址、本人搬家或接手前住戶地址；核准前不可用新地址下單。
- 在 LINE 內聯絡客服；訂單成立及狀態更新可接收 LINE 訊息。
- 安全教學及瓦斯緊急處理資訊。

## 管理者功能
- 核准／拒絕會員綁定及地址申請。
- 管理全體及商業客戶價格、版本與生效時間。
- 查看訂單、配送、司機、鋼瓶、合作店家、瓦斯金、提醒與營運分析。
- 查看備份與通知佇列摘要。

## 系統及資料
- Supabase：唯一正式即時資料來源，保存客戶、會員、地址、價格及訂單。
- Vercel：網站、API、LINE 通知與備份排程。
- Google Sheets：由 Supabase outbox 非同步備份；不是正式網站的即時讀取來源。
- 舊 Apps Script Web App：導向 Vercel 正式網站。
- 會員資料和個別價格只回傳給已驗證的本人；全客戶資料只在管理者 API 提供。

## 主機資料更新的同步現況
目前沒有找到「主機 SQL／備份檔一更新就自動寫入 Supabase」的流程。

既有 GitHub 工作流程 `Sync ShengLong members` 只有手動觸發，讀取 Drive 上的 `ShengLong_hour.bak`，將必要會員欄位寫進 Google Sheets 的「會員資料」頁籤。另有 `migrate-sheets-to-supabase.js` 可手動把 Sheets 資料匯入 Supabase，但正式 Vercel 排程只有 LINE 通知重試和 Supabase → Sheets 備份，沒有主機 → Supabase 排程。

因此，若更新的是主機原有 SQL／備份資料，Supabase **不會因此自動更新**。若更新是透過正式 LINE 網站送出並成功寫入 Supabase，正式資料庫會立即更新，Sheets 備份則由排程稍後處理。

## 尚待真人營運驗收
首次 LINE 登入、管理者核准、正式下單、LINE 推播及 Sheets 備份完整鏈路，仍需一筆受控測試資料驗證。
