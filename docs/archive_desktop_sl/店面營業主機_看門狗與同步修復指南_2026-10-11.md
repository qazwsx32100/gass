# 盛隆瓦斯 營業主機「開機自癒與即時同步」修復指南

**更新日期**：2026-10-11  
**適用目標**：店面櫃台營業主機（安裝舊進銷存系統、開單的那台電腦）

---

## 🎯 問題背景

店面主機的定時資料庫備份正常運作，但「即時同步服務（把訂單與庫存傳上網）」在主機休眠或重開機後沒有自動拉起，導致：
1. 司機 App 與雲端網站收不到今天（10/11）的即時新訂單。
2. 雲端庫存日期停留在昨天。

**根本原因**：看門狗腳本中的 Node.js 執行檔路徑過去寫死為單一路徑，當主機安裝於不同路徑時，看門狗便跳過了自動重啟。

---

## 🚀 現場修復方式（三選一，推薦方式 A）

### 【方式 A】一鍵批次檔修復（最推薦、最簡單）

1. 將本機桌面 `Desktop\sl\` 資料夾中的 **`修復店面主機開機自癒與同步.cmd`** 複製到店面營業主機（可透過隨身碟或 LINE 傳送）。
2. 在店面主機上，對 **`修復店面主機開機自癒與同步.cmd`** 點右鍵 ➔ 選擇 **「以系統管理員身分執行」**。
3. 工具會自動完成以下 5 項動作：
   * ✅ 自動尋找 Node.js 與盛隆系統目錄
   * ✅ 清除卡滯的舊進程與鎖
   * ✅ 重新註冊 Windows 開機自癒工作排程（`ShengLongBootWatchdog` & `ShengLongAutoStart`）
   * ✅ 立即啟動 `supervisor-sync.cjs` 守護程序
   * ✅ 驗證 Port 48999 與 Port 48998 通道暢通

---

### 【方式 B】若店面主機有 Git（一行指令更新）

若店面主機已有 Git 環境，在店面主機開啟 CMD 或 PowerShell：
```cmd
cd /d D:\test\shenglong-next
git pull
start-sync.bat
```
*(代碼已包含全部彈性 Node 路徑自動偵測，拉取後直接雙擊執行即可)*

---

### 【方式 C】店面主機純手動啟動（應急最速法）

若趕著立刻讓訂單上網，在店面主機上：
1. 打開檔案總管至 `D:\test\shenglong-next`
2. 找到 **`start-sync.bat`**
3. 點右鍵 ➔ **「以系統管理員身分執行」**
4. 看到黑視窗顯示 `啟動盛隆庫存同步 Supervisor Daemon...` 即可縮小維持在背景。

---
