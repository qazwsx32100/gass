## 系統關係

- LINE 正式會員、地址、價格、訂單、狀態與通知：Supabase。
- LINE 官網與管理後台：Vercel，只透過指定用途 RPC 存取 Supabase。
- Google Sheets：非同步備份、舊版查詢、財務或暫存匯入。
- 舊營業系統：SQL Server；尚未連上真正營業主機，因此新橋接保持停用。
- `盛隆瓦斯 v1.0 資料庫` 是舊版試算表架構，不能代表現行 LINE 官網正式資料來源。

## 仍需在營業主機核實

1. 正式舊系統連線的 SQL Server 名稱與資料庫名稱。
2. `customers`、`gas_oders` 是否與 2026-08-23 備份的欄位完全一致。
3. SQL Change Tracking 是否已啟用；未啟用時，既有訂單更新將使用指紋重掃。
4. Apps Script 專案實際綁定哪一份試算表。Drive 檔案清單無法證明綁定關係，不能只依檔名推定。

## 建議整理規則

正式主資料只保留 Supabase 一份；Google Sheets 只分成「正式備份」「舊版查詢」「財務」「暫存匯入」「測試／歸檔」五類。任何測試副本不得被 Apps Script、Vercel 或排程寫入。
