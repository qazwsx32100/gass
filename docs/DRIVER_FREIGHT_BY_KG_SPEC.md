## 📌 一、 改革緣起與核心算式

### 1. 改革背景
傳統瓦斯外送運費多採「按支計酬」（例如：4/10/16/20kg 均一價每支 $70 元、50kg 每支 $140 元）。  
為落實**「依實質負重勞力計酬」**、**「提升 50kg 超重規格激勵」**並建立**「季度留任與穩定獎勵」**，盛隆將外送運費全面升級為**「按公斤 (kg) 精算」**雙軌制。

### 2. 雙軌計費核心費率
1. **【月薪基礎運費 (Monthly Base)】**：**每公斤 $3.5 元**（每月隨薪資常態發放）
2. **【季獎金激勵池 (Quarterly Bonus)】**：**每公斤 $0.2 元**（每季 3 / 6 / 9 / 12 月結算累積發放）
3. **【樓層費 (Floor Fee)】**：維持獨立加成（如無電梯 +$30/層），單純補貼爬梯勞力，不被公斤稀釋。

## 📱 三、 司機端 APP (`app/driver/page.tsx`) 呈現規劃

### 1. 訂單卡片右下角（每筆外送即時收益）
在訂單卡片右下角金額旁，以高辨識度、極簡標籤呈現：
* **單桶 20kg 訂單**：
  `運費$70` `+季$4`
* **多桶訂單（例：20kg × 2 支 = 40kg）**：
  `40kg 運費$140` `+季$8`
* **大桶 50kg 訂單**：
  `50kg 運費$175` `+季$10`
* **若有樓層費**：
  `運費$70` `樓層費$30` `+季$4`

### 2. 頂部看板與跑馬燈統計列
* **頂部金幣看板**：
  `💰 今日運費：$2,450 元 (700 kg) ｜ 累積季獎金：+$140 元`  
  `🚚 配送中 2 筆 ｜ 今日已送達：35 支 (700 kg)`
* **下方公式跑馬提示**：
  `💡 運費機制：月薪 $3.5 / kg ｜ 季獎金 $0.2 / kg（每季結算發放）`

### 3. 司機「歷史與業績統計」彈窗（按月 / 按日查帳）
提供 3 大數據核心卡片，雙向透明對帳：
1. **【總送達總量】**：`35 支 (700 kg)`（附各規格細分：50k: 2支 / 20k: 30支 / 16k: 0支 / 10k: 0支 / 4k: 0支）
2. **【當月賺得運費 (月結)】**：`$2,450 元`（計算式：`700 kg × $3.5`）
3. **【本季累積獎金 (季結)】**：`$140 元`（計算式：`700 kg × $0.2`）
* **單筆歷史清單**：清楚標記每筆單之規格公斤數與雙軌收益（例：`20kg × 2支 (40kg) ➜ 月運費 $140 ｜ 季獎金 $8`）。

## 🛡️ 五、 系統架構相容性與技術防護（Directive #4 ERP 零動 Schema）

1. **舊 ERP 黑盒子零更動原則**：
   - 門市打單舊 ERP (`dbo.gas_oders`) 結構神聖不變，絕不執行任何 `ALTER TABLE` 或更動 Schema。
   - 舊系統原生已完整具備各規格欄位：`oder_50kg`, `oder_20kg`, `oder_16kg`, `oder_10kg`, `oder_4kg`。
2. **雲端與前端動態無損轉換**：
   ```typescript
   // 精算單據總公斤數
   const totalKg = (b50 * 50) + (b20 * 20) + (b16 * 16) + (b10 * 10) + (b4 * 4);
   
   // 月薪基本運費（每公斤 3.5 元）
   const monthlyEarnings = totalKg * 3.5;
   
   // 季獎金激勵池（每公斤 0.2 元）
   const quarterlyBonus = totalKg * 0.2;
   ```
3. **小數點取捨與精確度原則**：
   - 16kg ($56.0 / $3.2) 與 4kg ($14.0 / $0.8) 之季獎金具備 1 位小數。
   - 系統底層累計時採用**浮點精確累計**，於每日/每月/每季報表最終結算時**四捨五入至整數元**，保證分毫不差。
4. **生效日平滑過渡機制**：
   - 支援指定生效日期（例：設定 `WEIGHT_BASED_FREIGHT_EFFECTIVE_DATE = "YYYY-MM-01"`）。
   - 生效日前的歷史訂單維持舊制（按支計算），生效日起全面套用公斤新制，歷史帳目 100% 穩定無誤。
